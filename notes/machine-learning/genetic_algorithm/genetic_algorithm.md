# Genetic Algorithm

## Definition

A genetic algorithm (GA) is a computer program that uses **evolutionary theory** to solve problems. It is a type of artificial intelligence (AI) that mimics natural selection and reproduction.

## How it Works

- Start with a random population of solutions
- Evaluate the fitness of each solution
- Repeat until convergence or reach max iteration:
  - Select the fittest solutions (**selection**)
  - Swap genetic material between solutions (**crossover**)
  - Randomly alter solutions (**mutation**)

## Key Terms

- **Mutation**: A random change to a solution
- **Crossover**: The process of swapping genetic material between solutions
- **Selection**: The process of choosing the fittest solutions

## Applications

- Optimization problems
- Machine learning
- Evolutionary robotics
- Image and signal processing
- Financial modeling
